Command-line reference
======================

The installed executable is ``pyar``. Use ``pyar --help`` to choose a task and
``pyar COMMAND --help`` for exact arguments. Common calculation controls include
``--backend``, ``--check``, ``--dry-run``, configuration/profile controls and JSON
reporting where supported. Specialist tools expose their own arguments.

Do not assume an option exists on every task. The reference below is generated
from the canonical command registry/parser and describes this source version.
