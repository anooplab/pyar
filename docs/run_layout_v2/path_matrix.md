## Retained spellings and boundaries

Public roots: `aggregates`, `grow`, `microsolvation`, `reaction`, `scan_bond`,
`conformers`; legacy `solvation`. Modern `solvate` dispatches to
`modern_microsolvate`; `pyar-cli solvate` dispatches to legacy solvation.
Aggregate/react/conformer currently use caller-root APIs rather than a universal
`--output` interface. PR 0 proposes no new output option or public root rename.

Opaque execution contents include all optional native backend filenames under
`pyar/backends/` and provider scratch under `energy_gradient_providers.py`.
They are listed in the source inventory and remain outside rename scope, including
MLatom compatibility code. Model/runtime assets under AIMNet2 are not run outputs.
Compatibility re-export modules (`aggregate_state`, `solvation_state`, `reactor`,
`aggregator`, `conformer`, `workflows/_growth`) retain their public imports.

Source search was repository-wide across package, tests, docs and benchmarks;
native backend files are covered as opaque execution producers/consumers rather
than candidates for a detailed rename. External scripts not in this repository
cannot be exhaustively audited. Each migration must update its matrix row and
rerun corresponding consumers before approval.
