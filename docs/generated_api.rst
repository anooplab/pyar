Generated API from Docstrings
==============================

.. note::

   This file is overwritten during each Sphinx build by ``docs/conf.py``.
   It is committed only as a placeholder so the toctree remains valid when
   browsing the source tree before building the documentation.

Run:

.. code-block:: bash

   python -m sphinx -b html -W --keep-going docs docs/_build/html

The generated page will scan the ``pyar`` package and document modules from
Python docstrings.
