Reference data provenance
=========================

The catalogue records the current sources and limits. Before a case is release
eligible, preserve source name/version, DOI or URL, license, acquisition
record, exact input ordering, charge, multiplicity, method/backend version,
settings, reference values, input/reference hashes, and an independently
specified validation procedure.

Do not silently replace reference data or accept current PyAR output as its
own reference. A reference update needs a written scientific rationale,
source and method/backend version, old/new hashes, and scientific-owner review.
Keep external data outside the repository when the license does not permit
redistribution; record hashes and exact acquisition instructions instead.
