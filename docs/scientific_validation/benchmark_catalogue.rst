Benchmark catalogue
===================

The machine-readable inventory is
``benchmarks/scientific_validation/catalogue.json``. It points to the current
structure-comparison dataset, conformer-clustering pilot, external RGD1 TS
adapter, microsolvation comparison protocol, and backend scan validation.
Their reference types, source evidence, limits, and current release eligibility
are recorded per entry. All entries are marked ``release_eligible: false``:
the owner has not approved a complete candidate-bound release corpus.

The input data are not interchangeable. Geometry construction labels support
structural invariants; external optimized ensembles support a bounded
conformer-selection question; historical backend scans support interface
smokes. None alone qualifies all PyAR chemistry.

See :doc:`index` for tier rules and workflow coverage.
