# R2 documentation cleanup and validation

Status: implemented on the R2 review branch; exact-head CI and review are the
remaining acceptance evidence. This scope changes documentation and documentation
validation only. It does not change scientific algorithms, runtime behavior,
or public APIs.

## What changed

- Reconciled README and installation guidance with `pyproject.toml` and the CI
  matrix for the package name, Python support, optional extras, dependency
  groups, and command examples.
- Added a CLI reference covering every declared console script and linked it
  from the documentation navigation.
- Reworked the first-run example to use the current conformer workflow and an
  explicitly read-only preflight before execution; it states the external xTB
  requirement and avoids promising a fixed output layout or scientific result.
- Corrected architecture examples and distinguished the target design map from
  modules and APIs that are present today.
- Replaced repeated dated version snapshots in current migration guidance with
  the package version supplied by Sphinx configuration and advice to inspect
  installed versions and release notes. Dated audits remain historical records.
- Added `tools/check_documentation.py` and negative contract tests. CI now checks
  documented shell command flags against live CLI help, the architecture
  import example, CLI inventory, Python metadata/classifiers/CI agreement,
  documented extras and dependency groups, and the read-only first-run fixture.
- The documentation build writes HTML to the requested build directory. Sphinx
  also refreshes the tracked `docs/generated_api.rst`; that generated source
  change is restored after validation rather than included in R2. The generated
  API source remains maintained by Sphinx autodoc configuration.

The command checker validates that examples and flags still parse; it does not
validate scientific correctness. The preflight fixture performs no calculations.
Proprietary backend execution and scientific benchmarks are reserved for R3.
