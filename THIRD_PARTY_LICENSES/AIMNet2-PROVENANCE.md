# AIMNet2 Provenance

PyAR bundles AIMNet2 assets for its `aimnet_2` and `xtb-aimnet2` interfaces.

## Bundled Paths

- `pyar/AIMNet2/`
- `pyar/AIMNet2/models/*.jpt`

## Upstream Sources

- AIMNet2 historical repository: https://github.com/isayevlab/AIMNet2
- AIMNetCentral maintained project: https://github.com/isayevlab/aimnetcentral
- AIMNet2 wB97M-D3 model page: https://huggingface.co/isayevlab/aimnet2-wb97m-d3
- AIMNet2 2025 / B97-3c model page: https://huggingface.co/isayevlab/aimnet2-2025

The official AIMNet2 model pages identify the model repositories as MIT
licensed. The historical AIMNet2 GitHub repository is also identified as MIT
licensed. See `THIRD_PARTY_LICENSES/AIMNet2-LICENSE` for the preserved license
notice.
