# Clustering-distance regression corpus

This constructed corpus contains **84 geometries in seven pools**, with 42
proper-rotation, translation, and atom-permutation witnesses. Labels describe
chosen packing or torsion families. They are **not potential-energy basin
labels**, and the ranking energies are synthetic metadata.

| Pool | Constructed families | Purpose |
|---|---|---|
| Water dimer packing | 3.3–3.5 versus 6.3–6.5 Å separation | Packing sensitivity |
| Water dimer beyond cutoff | 14.9–15.1 versus 19.9–20.1 Å separation | Local SOAP cutoff limitation |
| Water dimer orientation | Co-oriented versus turned monomers | Hydrogen orientation sensitivity |
| Water–ammonia packing | Compact versus expanded heterodimer | Distinct fragment correspondence |
| Water trimer packing | Equilateral triangle versus linear chain | Whole-fragment permutations and shape |
| Benzene dimer packing | Stacked versus slipped idealized rings | Symmetric molecular aggregates |
| Butane torsions | Anti-like versus gauche-like indexed torsions | Molecular graph RMSD |

The water, ammonia, and benzene monomers are idealized constructions. The
butane template is RDKit-embedded and MMFF-minimized before applying the
specified torsions; those torsion-modified geometries are not subsequently
optimized. No claim of stationary points or chemically optimal packing is made.
Coordinates were generated by this repository's generator; no external
geometry database was copied. RDKit is needed only for regeneration.

## Reproduce and audit

```sh
.venv/bin/python benchmarks/clustering_distances/generate_dataset.py
.venv/bin/python -m pyar.scripts.benchmark_distances benchmarks/clustering_distances/dataset.json --audit-only
.venv/bin/python -m pyar.scripts.benchmark_distances benchmarks/clustering_distances/dataset.json --output /tmp/clustering-distances.json
.venv/bin/python -m pytest -q tests/test_structural_distances.py tests/test_clustering_distance_dataset.py
```

The stored XYZ coordinates are authoritative. Regeneration can depend on the
RDKit version. Audits verify composition consistency, finite coordinates,
proper rotations, full permutation witnesses, monomer connectivity, and a
1.2 Å minimum intermolecular contact. Cross-family pair-distance spectra
independently establish geometric noncongruence. Comparator output never
determines the fixture labels.

## Interpretation

The runner compares seven configurations using average-linkage clustering,
with the number of clusters set to the number of constructed families. It
reports adjusted Rand index, rigid-copy distance, runtime, actual descriptor
and distance paths, algorithm/distance fallbacks, package versions, code hashes,
and dataset hashes. An ARI of 1 means these constructed families were recovered;
it does not measure chemical or basin-identification accuracy.

The initial reviewed run recovered all seven pools with all-atom graph RMSD.
Fragment matching recovered all six aggregate pools; the molecular butane pool
used its recorded graph-RMSD fallback. SOAP/REMatch recovered six pools, preserving individual
candidates in the beyond-cutoff pool when its matrix had no variation.
Heavy-atom graph RMSD could not distinguish the water orientation families.
These are expected representation limits. The run also exposed and motivated
a feature-scaling fix: large, nearly constant SOAP columns must not turn rigid
transform roundoff into artificial diversity.

Fragment matching is a bounded approximation: it enumerates permitted
fragment assignments and anchor rotations, selects internal mappings in that
global frame, then scores a single global proper Kabsch fit. The larger of both
directional results is used. Its mapped distance is an upper bound on the exact
symmetry RMSD; it need not satisfy every metric axiom. It never discards packing
by independently aligning and scoring individual monomers.

SOAP/REMatch uses normalized local environments and normalized whole-structure
similarities, following the [DScribe tutorial](https://singroup.github.io/dscribe/latest/tutorials/similarity_analysis/kernels.html)
and [De et al. (2016)](https://doi.org/10.1039/C6CP00415F). Transport is implemented
with bounded log-domain Sinkhorn updates; a regression compares it with DScribe's
reference implementation. Descriptor and algorithm defaults remain unchanged.
Production policy still requires labelled, optimized aggregate and conformer
benchmarks, including flexible monomers and larger fragment counts.
